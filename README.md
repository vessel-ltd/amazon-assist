# Amazon 月別領収書（非公式）

Amazon.co.jpにログインしているChromeで、年月を指定して領収書／購入明細書をまとめてPDF保存するManifest V3拡張です。Vessel合同会社がMITライセンスで公開しています。Amazonとは提携しておらず、Amazonの公式製品ではありません。

Chromeウェブストアにはまだ掲載されていません。現在はソースから読み込んで利用できます。

[プライバシーポリシー](PRIVACY.md) · [不具合報告・開発](CONTRIBUTING.md) · [MITライセンス](LICENSE)

## インストール

1. Chromeで `chrome://extensions` を開き、「デベロッパーモード」をオンにします。
2. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
3. このリポジトリをダウンロード・展開した場所の **extensionフォルダー** を選択します。
4. Chromeの拡張機能メニューから「Amazon 月別領収書（非公式）」を開きます。

## 使い方

1. 同じChromeプロファイルでAmazon.co.jpにログインします。
2. 拡張のアイコンをクリックし、出力年月を選びます。
3. 「領収書／購入明細書出力」を押します。
4. 取得用のAmazonタブが1つ開きます。注文一覧と印刷ページの表示が完了するのを待って読み取り、取得完了後にタブを閉じて印刷画面を開きます。取得中はそのタブを操作・閉じないでください。
5. 送信先「PDFに保存」、用紙「A4」で保存します。推奨ファイル名は `Amazon領収書_2026-08.pdf` の形式です。

見本のように日時・ページ番号を付ける場合は「ヘッダーとフッター」をオンにします。注文ごとに改ページします。商品数が多い注文は複数ページになる場合があります。元の見本PDFは上書きしないでください。

## 動作と制限

- 注文日の年月で抽出し、新しい注文日から並べます。年内の全ページを確認するため、件数によって時間がかかります。
- Amazonの「領収書等」→「印刷可能な注文概要」の内容を使用します。タイトル、金額、宛先、支払い方法などを独自に書き換えません。
- v1.1.0から、HTMLの直接取得を廃止し、Chromeに表示されたDOMを読み取ります。Amazonの暗号化された注文情報はAmazon自身のスクリプトで復号・表示されるまで待ちます。
- 現在のAmazonの情報を使用するため、以前に保存したPDFの配送状況などとは異なる場合があります。
- 適格請求書の一括取得、CSV、宛名変更、再発行表示の削除は対象外です。
- 印刷ページがない注文、ログイン切れ、認証、HTML変更、通信エラーは全体を中止して表示します。一部を黙って省いたPDFは作りません。
- PDFの保存はChrome標準の印刷機能です。自動ダウンロードや固定パスへの無確認保存は行いません。
- Amazon.co.jpへのアクセスだけを許可します。注文情報は画面のメモリに保持し、外部サービスへの送信や永続保存は行いません。Amazonの商品画像・スタイルはAmazonの配信サーバーから読み込みます。
- 元の有料拡張のコードは使用していません。Amazon注文履歴内の既存拡張UIにも依存しません。

## 開発・検証

`npm ci && npm run build && npm test` でパーサー・ページ送り・復号待ち・異常時の中止処理を検証します。npm依存はテスト用で、拡張自体には必要ありません。`reader-content.js` は `core.js`、`rendered.js`、`reader-bridge.js` から生成するため、変更後はビルドしてください。

### 以前のバージョンからの更新

Chromeの `chrome://extensions` で「Amazon 月別領収書（非公式）」の再読み込みボタンを押してから、拡張の画面を開き直してください。新しいコンテンツスクリプトを登録するため、画面のCtrl+Rだけでは更新できません。画面上部は `v1.1.4` になります。`app.html` をファイルとして直接開く方法には対応しません。

### 診断ログでの確認（v1.1.3）

出力が成功・失敗・中止したあとに「診断ログを保存」を押すと、`Amazon診断_年月_日時.json` をダウンロードできます。診断ログには注文番号が含まれるため、公開Issue・PRには添付しないでください。診断ログはGit管理対象外です。

ログには対象年月、注文番号、時刻、取得段階、件数、DOMの構造を示す真偽値、分類済みエラーコードを含みます。住所・氏名・商品名・金額・支払い情報・URL・HTML・生のエラー文は含めず、外部へ自動送信しません。画面を閉じると未保存ログは消え、再実行すると直前のログを置き換えます。イベントは最大2,000件で、超過時は古いものを削除し `droppedEvents` に記録します。

`orders_selected` が抽出件数、`receipt_ready` が取得できた注文、`page_state` が表示状態、`page_failed` / `failed` が失敗箇所です。`print_requested` は印刷呼び出しまでの記録で、PDF保存成功を意味しません。実際のPDFと注文履歴を別途照合してください。診断ログだけで画面の完全再現や金額照合はできません。

v1.1.2では「領収書等」のメニューがない注文も、Amazonの印刷可能な注文概要を開いて取得可否を確認します。印刷内容を確認できなければ、注文を黙って省かず中止します。ポイント支払いの説明と金額欄が重ならないように印刷時の列幅も調整しています。

個人データを含むPDF・実画面HTMLはGit管理対象外です。任意のローカル確認用 `tests/check-local-fixtures.mjs` は `tmp/fixtures/` の実画面データがある場合のみ実行できます。

## 申請用パッケージ

`npm run package` で拡張本体とMITライセンスだけを含むZIPを `output/store/` に作成します。Python 3が必要です。`node_modules/`、テスト、実データ、診断ログは含めません。申請時の説明文と準備事項は [ストア申請ガイド](docs/STORE_SUBMISSION.md) を参照してください。
